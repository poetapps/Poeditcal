# Poet Audio 1.0.0

The first public release of Poet Audio, a local-first voice editor for Apple-silicon Macs.

## Highlights

- Edit recordings by removing words from a timestamped transcript.
- Apply adaptive voice cleanup, loudness normalization, breath control, and optional AI noise reduction.
- Download the verified noise-reduction model only when you choose to use it.
- Export a lossless WAV with optional transcript, SRT, and WebVTT files.
- Save and reopen Poet Audio projects.
- Receive signed updates directly in the app through Sparkle.

Poet Audio requires macOS 15 or newer.
